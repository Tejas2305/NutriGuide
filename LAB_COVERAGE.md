## Summary of Java Viva Highlights
1. **Strict Java 8 Compliance**: Zero Stream API, zero Lambdas, zero method references, zero `Optional`.
2. **True Layered Architecture**: Swing GUI → Service Layer → DAO Layer → JDBC → MySQL (Zero JDBC or SQL in UI).
3. **Safe Memory & Resource Lifecycle**: Every JDBC resource (`Connection`, `PreparedStatement`, `ResultSet`) closed via try-with-resources.
4. **Defensive Programming**: Immutable constants, defensive copy constructors, encapsulated models, input validation utilities.
