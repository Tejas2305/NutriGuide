TITLE: Develop a Java application demonstrating the use of default, parameterized, and copy 
constructors for object initialization and data management. 
Problem Statement 
Develop a Java application demonstrating the use of default, parameterized, and copy 
constructors for object initialization and data management. 
Learning Objectives 
To understand and implement default, parameterized, and copy constructors for object initialization.
Theory 
Constructors are special member functions that are automatically invoked when an object 
is created. Java supports default constructors provided by the compiler, parameterized 
constructors for initializing objects with user-defined values, and copy constructors 
(implemented manually) for creating duplicate objects. Constructors improve code 
readability and simplify object initialization while supporting object-oriented programming 
principles. 
Exercise

and roll number. 
2. Develop a Mobile Phone Inventory System using different constructors to initialize 
mobile details and create duplicate object records.

TITLE: Develop a Java application demonstrating method overloading and the use of static 
variables, methods in class design. 
Problem Statement 
Develop a Java application demonstrating method overloading and the use of static 
variables, methods in class design. 
Learning Objectives 
To implement method overloading and use static variables and methods in Java programs. 
Theory 
Method overloading allows multiple methods to have the same name with different 
parameter lists, enabling compile-time polymorphism. The static keyword is used for 
variables and methods that belong to the class instead of individual objects. Static members 
share common data among all objects and reduce memory usage. These concepts improve 
code flexibility, readability, and efficient resource management.

To implement inner classes and anonymous classes for improving encapsulation and event handling

Theory 
An inner class is a class defined inside another class and has access to all members of the enclosing 
class, including private members. Inner classes help improve code organization and logical 
grouping of related classes. Anonymous classes are unnamed inner classes that are instantiated only 
once and are mainly used for implementing interfaces or abstract classes. They simplify code by 
eliminating the need for separate class definitions. These concepts are widely used in Java GUI 
programming and event handling

class performs an action.

Problem Statement

To implement inheritance and interfaces for achieving code reusability and abstraction. 
Theory 
Inheritance allows one class to acquire the properties and methods of another class, promoting code

multiple inheritance of type. Together, inheritance and interfaces support polymorphism and 
modular software development. They are fundamental concepts of object-oriented programming.

The super keyword is used to refer to the immediate parent class in Java. It can invoke

proper constructor chaining during object creation. It is an important concept in inheritance 
and method overriding.

To implement the final keyword with variables, methods, and classes. 
Theory 
The final keyword restricts modification in Java programs. A final variable cannot be reassigned 
after initialization. A final method cannot be overridden by subclasses, while a final class cannot 
be inherited. This improves security, prevents accidental modifications, and increases program 
reliability. Final is commonly used for constants and immutable classes.

TITLE: Develop a Java application to establish connectivity with a database and perform data 
retrieval using the SELECT operation. 
Problem Statement 
Develop a Java application to establish connectivity with a database and perform data 
retrieval using the SELECT operation. 
Learning Objectives 
To establish database connectivity and retrieve records using JDBC SELECT statements. 
Theory 
Java Database Connectivity (JDBC) is a standard Java API that enables communication between Java 
applications and relational databases. It provides a platform-independent mechanism to connect to 
databases such as MySQL, Oracle, PostgreSQL, and SQL Server. Before executing SQL statements, 
a JDBC driver is loaded and a connection is established using the DriverManager class. The 
Connection object represents an active connection to the database, while the Statement object is used 
to execute SQL queries. The SELECT statement retrieves records from database tables based on 
specified conditions. The retrieved records are stored in a ResultSet object, which allows sequential 
access to the data. JDBC simplifies database programming and is widely used in desktop, web, and 
enterprise applications. 
Exercise

TITLE: Develop a Java application to establish connectivity with a database and perform 
INSERT, UPDATE, and DELETE operations. 
Problem Statement 
Develop a Java application to establish connectivity with a database and perform INSERT, 
UPDATE, and DELETE operations. 
Learning Objectives 
To perform database modification operations using JDBC. 
Theory 
JDBC allows Java applications to perform database manipulation using SQL Data 
Manipulation Language (DML) statements such as INSERT, UPDATE, and DELETE. The 
INSERT statement adds new records into database tables, UPDATE modifies existing 
records, and DELETE removes unwanted records. These operations are executed using the 
Statement or PreparedStatement interface. PreparedStatement is generally preferred 
because it supports parameterized queries, improves performance, and prevents SQL 
injection attacks. Proper transaction management ensures that database modifications are 
performed safely and consistently. These operations form the basis of almost every 
database-driven application such as banking systems, hospital management systems, and 
student information systems.

The JDBC API consists of several classes and interfaces that facilitate database

databases. Understanding these core components is essential for developing database 
applications using Java.

TITLE: Demonstration and exploration of JDBC classes and interfaces (PreparedStatement, 
and ResultSet). 
Problem Statement 
Demonstration and exploration of JDBC classes and interfaces (PreparedStatement, and 
ResultSet). 
Learning Objectives 
To implement PreparedStatement and ResultSet for secure query execution and data 
retrieval. 
Theory 
PreparedStatement is an advanced JDBC interface used to execute precompiled SQL 
statements with parameters. Unlike the Statement interface, PreparedStatement allows SQL 
queries to be compiled only once and executed multiple times with different values, thereby 
improving performance. It also protects applications against SQL injection attacks by 
separating SQL code from user input. The ResultSet interface stores the records returned 
by SQL SELECT queries. It provides various methods such as next(), getInt(), getString(), 
and getDouble() for accessing retrieved data. PreparedStatement and ResultSet together 
provide secure, efficient, and flexible database interaction and are widely used in enterprise 
Java applications. 
Exercise 
1. Create a login application using PreparedStatement to check username and password. 
2. Create a Java application using PreparedStatement to authenticate hospital staff 
login (doctor/nurse/login ID and password). Display appropriate access messages based

ResultSet. 
Problem Statement 
Develop a Java application using JDBC to navigate and retrieve records from a ResultSet. 
Learning Objectives 
To navigate and retrieve records using ResultSet methods. 
Theory 
A ResultSet object contains data retrieved from a database after executing a SELECT 
query. It acts like a cursor that points to one row of the result at a time. Initially, the cursor 
is positioned before the first row. Various methods such as next(), previous(), first(), last(), 
absolute(), and relative() allow movement through the records. Data from each column can 
be retrieved using methods like getString(), getInt(), and getDouble(). Scrollable and 
updatable ResultSets provide greater flexibility for navigating and modifying retrieved 
data. ResultSet plays a crucial role in displaying and processing database information in 
Java applications. 
Exercise 
1. Create a program to display database records one by one using ResultSet. 
2. Create a Java program that retrieves employee records from a database and

Problem Statement 
Write a Java program using the Thread class to create multiple threads and demonstrate 
their lifecycle. 
Learning Objectives 
To create and manage multiple threads using the Thread class. 
Theory 
A thread is the smallest unit of execution within a Java program. Multithreading enables 
multiple tasks to execute concurrently, improving application performance and 
responsiveness. Java provides the Thread class for creating threads by extending it and 
overriding the run() method. A thread passes through different lifecycle stages including 
New, Runnable, Running, Blocked/Waiting, and Terminated. The scheduler manages 
thread execution based on system resources. Methods such as start(), sleep(), join(), and 
interrupt() control thread behavior. Multithreading is commonly used in games, web 
servers, animation, and background processing applications.

Problem Statement 
Write a Java program to create and execute multiple threads using the Runnable interface. 
Learning Objectives 
To create multiple threads using the Runnable interface. 
Theory 
The Runnable interface provides an alternative approach to creating threads in Java. A class 
implementing Runnable defines the run() method that contains the code executed by the 
thread. The Runnable object is passed to a Thread object, which starts execution using the 
start() method. Unlike extending the Thread class, implementing Runnable allows a class 
to inherit from another superclass, making the design more flexible. Runnable separates 
task definition from thread execution, resulting in better code organization and reusability. 
It is widely used in multithreaded enterprise applications and thread pool implementations. 
Exercise 
1. Create a program using Runnable to run two tasks simultaneously. 
2. Create a Java program using the Runnable interface where two tasks run simultaneously: 
one thread performs deposit operations, and another performs withdrawal operations, both 
displaying results concurrently.

TITLE: Develop a Java application demonstrating socket programming for communication 
between a client and a server. 
Problem Statement 
Develop a Java application demonstrating socket programming for communication 
between a client and a server. 
Learning Objectives 
To establish communication between client and server using Java sockets. 
Theory 
Socket programming enables communication between computers over a network using 
TCP/IP protocols. Java provides the Socket class for client-side communication and the 
ServerSocket class for server-side communication. A server listens for client requests on a 
specific port, while clients establish connections using the server's IP address and port 
number. Once connected, data is exchanged using input and output streams. Socket 
programming supports reliable communication between distributed systems and is widely 
used in chat applications, online gaming, file transfer systems, remote monitoring, and 
client-server architectures. 
Exercise 
1.Create a simple client-server chat application using sockets. 
2. Create a Java program using socket programming where the client sends a message to the server, 
and the server returns the same message back (echo system).

TITLE: Develop a Java application demonstrating Remote Method Invocation (RMI) using 
stub and skeleton components for remote communication. 
Problem Statement 
Develop a Java application demonstrating Remote Method Invocation (RMI) using stub 
and skeleton components for remote communication. 
Learning Objectives 
To implement Remote Method Invocation for distributed Java applications. 
Theory 
Remote Method Invocation (RMI) is a Java technology that enables an object running on 
one Java Virtual Machine (JVM) to invoke methods of an object running on another JVM 
located on a different machine. RMI simplifies distributed application development by 
allowing remote objects to behave like local objects. It consists of remote interfaces, remote 
object implementations, the RMI registry, and client-server communication. The registry 
maintains references to remote objects, allowing clients to locate and invoke them. RMI 
provides platform-independent communication, object serialization, and automatic 
network handling, making it suitable for distributed enterprise applications. 
Exercise 
1. Create a remote calculator service using Java RMI 
2. Create a Java application using RMI where the server converts temperature values between 
Celsius and Fahrenheit. The client sends input temperature and receives converted output.

TITLE: Write a JSP application to demonstrate the basic concepts of Java Server Pages. 
Problem Statement 
Write a JSP application to demonstrate the basic concepts of Java Server Pages. 
Learning Objectives 
To develop dynamic web pages using Java Server Pages. 
Theory 
Java Server Pages (JSP) is a server-side technology used for developing dynamic web 
applications. JSP allows Java code to be embedded within HTML pages using special JSP 
tags. When a JSP page is requested, the web server automatically translates it into a servlet, 
compiles it, and executes it to generate dynamic web content. JSP supports implicit objects, 
directives, scripting elements, expression language, and standard tag libraries. It simplifies 
web development by separating presentation from business logic. JSP is commonly used 
with Servlets and JDBC for building database-driven web applications. 
Exercise 
1. Create a JSP page to display student information entered by the user 
2. Create a JSP application that takes user registration details such as Name, Email, 
Phone Number, and Password, and displays the submitted information on a result JSP 
page.

TITLE: Write a JSP application to demonstrate CRUD operations. 
Problem Statement 
Write a JSP application to demonstrate CRUD operations. 
Learning Objectives 
To implement Create, Read, Update, and Delete operations using JSP and a database. 
Theory 
CRUD stands for Create, Read, Update, and Delete, which represent the four basic database 
operations performed in web applications. JSP works together with Servlets and JDBC to 
implement these operations. Users interact with HTML forms created using JSP, while 
JDBC executes SQL statements to manipulate database records. INSERT adds new 
records, SELECT retrieves information, UPDATE modifies existing data, and DELETE 
removes unwanted records. Proper validation, exception handling, and session 
management improve application reliability and security. JSP CRUD applications are 
widely used in employee management systems, online shopping portals, hospital 
management systems, banking applications, and other enterprise software. 
Exercise 
1. Create a JSP-based application to add, update, delete, and view employee details 
2. Create a JSP-based application to manage patient records using CRUD operations. 
Include fields such as patient ID, name, age, disease, and treatment status.
